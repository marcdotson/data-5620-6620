# Difference-in-Differences


- The “differences” are the changes in the treated and untreated groups
  before and after the treatment which are then differenced (*The
  Effect* p. 441)
- The parallel trends assumption is about the post-treatment trend,
  which is a counterfactual and thus unobservable (*The Effect*
  p. 445-446)
- Use the change in the untreated group to represent all non-treatment
  changes in the treatment group (*The Effect* p. 446)
- In choosing an untreated group, we want a group that wouldn’t suddenly
  change around the time of treatment, the groups are generally similar,
  and they had similar trajectories before treatment (*The Effect*
  p. 447)
